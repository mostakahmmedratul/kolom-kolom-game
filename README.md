# ✏️ Kolom-Kolom Game

### A Childhood-Inspired Pen Battle Game

**Kolom-Kolom Game** is a fun, interactive browser-based game inspired by the nostalgic pen games we used to play during childhood and school days. Challenge a computer-controlled opponent, aim carefully, and use strategy to win the match!

🌐 **Play Online:** [Play Kolom-Kolom Game](https://kolom-kolom-game-git-version-12-ratul-verse.vercel.app/)

📂 **Source Code:** [GitHub Repository](https://github.com/mostakahmmedratul/kolom-kolom-game)

## ✨ Features

- 🖊️ **Pen Selection:** Choose your preferred pen type before playing.
- 🤖 **AI Opponent:** Challenge a computer-controlled opponent.
- 🎯 **Multiple Difficulty Levels:** Choose Easy, Medium, or Hard to match your skill level.
- 🏆 **Target Score:** Play towards a selected winning score.
- 🧠 **Strategic Gameplay:** Aim carefully and use the right amount of force to push your opponent's pen off the playing surface.
- ⚙️ **Physics-Based Movement:** Experience pen movement, collisions, and momentum.
- 🔊 **Sound Effects:** Enjoy interactive audio feedback during gameplay.
- ⏸️ **Pause and Resume:** Pause the match and continue when you're ready.
- 🔄 **Replay:** Start a new match and try to beat your previous performance.
- 🎉 **Victory Effects:** Celebrate your win with visual effects.
- 🌐 **Play in Your Browser:** No separate game installation is required.

## 🕹️ How to Play

1. Open the [Kolom-Kolom Game website](https://kolom-kolom-game-git-version-12-ratul-verse.vercel.app/).
2. Choose your preferred pen type.
3. Select a difficulty level: Easy, Medium, or Hard.
4. Set your target score.
5. Aim your pen by clicking and dragging on the playing area.
6. Release to flick your pen toward your opponent.
7. Try to knock your opponent's pen off the playing surface while keeping your own pen on the table.
8. Score points and reach the target score before the computer does!

**Tip:** Good aim and controlled force can make the difference between winning and losing.

## 🛠️ Technologies Used

This project uses modern web technologies to deliver an interactive gaming experience.

- **React** — Building the user interface and managing game state.
- **TypeScript** — Adding type safety and maintainable code.
- **Vite** — Development server and production build tooling.
- **HTML5 Canvas** — Rendering the game scene and animating pen movement.
- **Tailwind CSS** — Styling the user interface.
- **Custom Physics Engine** — Handling movement, momentum, and collisions.
- **Computer AI** — Calculating opponent moves at different difficulty levels.
- **Lucide React** — Interface icons.
- **Canvas Confetti** — Victory animations.
- **Vercel** — Hosting and deploying the web application.

## 🚀 Run Locally

Want to run the game on your own computer or contribute to its development? Follow these steps.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/mostakahmmedratul/kolom-kolom-game.git
```

### 2. Navigate to the project directory

```bash
cd kolom-kolom-game
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to play the game.

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
